# FSD Event Management Portal

A full-stack event management portal — vanilla HTML/CSS/JS frontend, Node/Express backend, MongoDB database.

## Stack

- **Frontend**: HTML, CSS, vanilla JavaScript (no framework)
- **Backend**: Node.js, Express
- **Database**: MongoDB (Mongoose)

## Project structure

```
client/   # HTML/CSS/JS frontend
server/   # Express API
docs/     # Schema and API contract docs
```
